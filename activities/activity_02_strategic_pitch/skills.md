# Skills Chain
> Run /cxo-strategic-brief then /cfo-deck-builder in the same conversation. (~7 min)

## skill_chain
/cxo-strategic-brief → /cfo-deck-builder → /human

## context

The sequence matters. /cxo-strategic-brief frames the narrative first. /cfo-deck-builder builds the financial model on top of that strategic frame. Run them in order in the **same conversation**.

## prompt
/cxo-strategic-brief C-level strategic framing for CFO Rebecca Torres at Cascade Retail Holdings, $9M O2C transformation. Torres is ex-Nordstrom VP Finance — data-driven, hates fluff. Use all research in this conversation: web financials, investor presentation analysis, and deal context. Frame Genpact as the partner who delivers operational margin recovery — measurable financial return, not process improvement. 600 words.

## prompt_optional
Add this line before pasting to sharpen the output — skip if pressed for time:

"Torres' exact words: [paste the specific quote or financial figure you extracted from the investor presentation]"

The skill works without this. With it, the framing reflects Torres' own language rather than a generic CFO narrative.

## prompt_2
/cfo-deck-builder CFO business case for Rebecca Torres, Cascade Retail Holdings. $9M O2C engagement over 3 years.

Use these numbers from the investor presentation (already in this conversation):
- DSO: 44 days → target 30 days (peer benchmark 35)
- Invoice error rate: 6.8% → target 2%
- O2C cost: $5.20/invoice → target $3.00
- Working capital locked: $28M excess
- Torres' mandate: 150bps margin improvement in 18 months

Build: ROI model (NPV, IRR), payback period, cost of waiting, downside case, 3 opening statements. 800 words.

## prompt_2_optional
Add this line before pasting if you found Torres' exact words in Intel — skip otherwise:

"Torres said: [paste her direct quote about margin improvement or ROI expectations]"

The skill works with the numbers above. With her direct quote, the opening statements use her own language — harder to dismiss.

## tip

Notice how /cfo-deck-builder produces a sharper ROI model because /cxo-strategic-brief already established the strategic frame? Each skill compounds the previous. The financial argument is stronger when it sits inside a strategic narrative.

## checkpoint

Do you have a year-one ROI figure that uses Cascade's own numbers? And a "cost of waiting" calculation — what does each month of delay cost Torres in working capital? If either uses a benchmark rather than Cascade's specific data, go back and extract the actual number.
