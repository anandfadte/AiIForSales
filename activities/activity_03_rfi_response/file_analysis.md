# File Analysis
> Analyze the RFI to find which questions actually determine the shortlist. (~4 min)

## plugin
File Analysis

## context

Upload the RFI document BEFORE attempting to answer any questions. The analysis in this phase tells you where to spend your time — which questions are differentiating and which are standard.

Upload **sample_rfi.docx** using the File Analysis plugin, then run the prompt below in the same conversation.

## prompt
I'm uploading TrueNorth Insurance Group's RFI for claims processing transformation (15 questions). Analyze it:
1. What are the KEY THEMES across the 15 questions? (What do they care about most?)
2. Which questions are STANDARD (every vendor can answer similarly) vs. DIFFERENTIATING (where the answer determines the shortlist)?
3. Which questions test for AI/ML depth? (Questions 3, 5, 12, 13)
4. Which questions test for insurance domain expertise? (Questions 1, 2, 7, 8, 10)
5. Where is TrueNorth testing for cultural fit vs. capability? (Question 15)
6. What's the RISK — which questions could eliminate us if answered poorly?

Prioritize where I spend the most time crafting responses. 400 words.

## tip

The most important output of this phase is PRIORITIZATION. If you answer all 15 questions with equal depth, you've failed — the differentiating questions need 3x the effort of the standard ones. Focus your skill chain (Phase 5) on the differentiating questions first.

## checkpoint

After analysis: can you rank the 15 questions by differentiation value? Do you know which 3-4 questions most likely determine whether Genpact makes the shortlist? If you can't rank them, re-run the analysis with a sharper focus on "what would cause TrueNorth to eliminate a vendor."
